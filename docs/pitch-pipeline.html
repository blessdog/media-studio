Media Studio · Pipeline Brief · August 2026

A compiler for explainer film.

The picture is generated. The explanation is compiled. They meet inside a professional compositor — which is why the result can be beautiful and exact at the same time.

The problem with generated video

Generative video is good at spectacle and bad at argument. Ask a model for sixteen identical envelopes and it returns eight different ones. That is fatal for explanation, because explanation depends on sameness: this is the same coin as before, this bar is exactly twice that one, this mark matches that mark. A model that re-imagines every frame cannot promise any of it.

Conventional motion graphics solve exactness and lose the picture — they look like slide decks. Hand animation solves both and costs a studio.

The insight

Separate the beautiful from the exact. Every frame has two jobs, and they want opposite tools. The world — texture, light, atmosphere — should be generated, because that is what diffusion is genuinely exceptional at. The mechanism — the thing the viewer is supposed to learn — should be compiled from code, because code can guarantee what a model cannot.

Then composite them in DaVinci Resolve's Fusion, a node-based compositor that shipped in Hollywood VFX before Blackmagic bought it. Not a wrapper around it. Inside it, driven by its own scripting API.

Each visual recipe names the renderer it wants — a hosted image API, a hosted node graph, or our own rented GPU — so the expensive question ("where does this run?") is a line of configuration rather than a rewrite. That seam is what lets cheap exploration and heavy generation share one pipeline.

Why this is defensible

The mark below is a pure function of a seed. Compile it twice with the same seed and you get a byte-identical node graph; compile with a different seed and you get a different mark. The film's entire security argument — the same coin always leaves the same trace, and a different coin cannot — is therefore enforced by the code that draws it, not promised in a prompt.

SEED 4471 · graph d61dab1c
SEED 9182 · graph a8d466f1

The two share 6 of 25 cells — distinguishable at a glance, which is the pedagogical requirement. No diffusion model can offer that guarantee, and no template library can either.

The second moat is the look is data. Palette, edge softness, ink opacity, bleed and blend mode live in one theme file; components read tokens and are structurally forbidden from containing a colour. Changing the entire film's visual identity is one file. A test proves it by compiling every component against a deliberately hostile second theme and failing if the output doesn't change.

Verification is the product

The expensive failure in an automated pipeline is not a crash. It is a run that reports success and produces something subtly wrong, because every downstream stage then carries the error forward and the final result looks plausible. Three gates exist specifically to make that impossible.

Graph manifest

Every tool, value, connection and keyframe is hashed before export and re-read after import, then compared field by field. Counting nodes is not enough — the count can match while the wiring is wrong.

Motion & localisation

The render must actually move, in the window the component declared, in the region it declared, while leaving the rest of the plate intact. A static shape fails. A full-frame wash fails. A composite that replaced the plate instead of staining it fails.

Exact environment

Product, version, project and timeline are all asserted before any measurement is trusted.

What this already caught

Importing a composition silently discards the nodes that connect it to the picture. The first round-trip returned all 18 nodes with correct names and types — and rendered nothing, because the input was dangling and there was no output node. A node-count check passes that. The manifest gate did not.

We rent the compute rather than the output. Heavy generation runs on GPUs rented by the hour from a spot marketplace — the tooling searches for capacity under a price cap, refuses unreliable hosts, cycles automatically past dead ones, and destroys the box when the work is done, at which point billing stops. Scaling up is renting more boxes; the job shards across them over one tunnel each.

Compositing throughput is measured on one workstation with no render farm. Generation cost is hourly compute, not per-asset vendor pricing, so the figure that actually governs unit economics is the re-roll multiplier — how many candidates are generated per frame that ships. That number is not yet instrumented on this lane, and any per-film cost quoted before it is should be read as a floor rather than an estimate.
