## 3. THIRD — the Ableton `.als` parse (pipeline G2)

The trigger map answers *where in the finished track does each sample fire*, so
the meme's own frames can land on the Resolve timeline at that beat. Three
possible producers (CLIP-LANE §4); **G2 is the one buildable now** — no SP-404 on
the desk, no hardware, no routing.

### Verified today against Ryan's own project **[V]**

`~/Music/Ableton/Live Recordings/thunderdome Project/thunderdome.als`
(188 `.als` on disk):

- **gzipped XML**, Ableton Live 12.4 — `gzip` + any XML parser, no Ableton
  automation, no MCP.
- Contains `<AudioClip>`, `<MidiClip>`, `<CurrentStart>`, `<CurrentEnd>`,
  `<SampleRef>`, `<MidiNoteEvent>`.
- **Times are in BEATS, not seconds.** `<CurrentEnd Value="3852.032">` at
  tempo 120 = 1926 s ≈ 32 min, which matches a long mastered rip. So
  `seconds = beats * 60 / bpm`.
- **Master tempo is readable** — `<Tempo>` → `<Manual Value="120">`.
- **`<SampleRef><FileRef>` carries an absolute `<Path Value="/Users/…">`** as
  well as a `<RelativePath>`. **The absolute path is the join**: hash that file,
  look it up in rectum's ledger by `clip_hash`.

### Unknowns — resolve each BY EXERCISING, not by reading

1. **Which `<Tempo>` is the master?** There are **11** `<Tempo>` elements in one
   project **[V]**. Picking the wrong one silently scales the whole timeline.
2. **Is there tempo automation?** If tempo varies, `beats → seconds` is not one
   multiply and needs the tempo envelope integrated. Check before assuming.
3. **Arrangement vs Session clips.** A finished track is the **Arrangement**.
   Session-view clip slots must be excluded or they produce phantom placements
   at bogus times.
4. **Warp / clip start offset.** `<CurrentStart>` is position on the timeline;
   the clip's own start *inside the sample* is what feeds `source_in_secs` — the
   field that makes the picture chop in sync with the audio. They are different
   numbers; do not conflate them.
5. **Chopped samples** should appear as many `<AudioClip>` entries referencing
   one file. That *is* the trigger map. Confirm on a project that actually has
   chops — `thunderdome` has only 1 AudioClip and 1 MidiClip **[V]**, so it
   proves the format but **not** the chop case. Ask Ryan for a chopped set, or
   make one.

### Output contract — one artifact, three possible producers

```json
{ "version": 1, "bpm": 120, "source": "thunderdome.als",
  "entries": [
    { "clip_hash": "…", "source_path": "/Users/…/x.wav",
      "track_start_secs": 42.15, "duration_secs": 0.5,
      "source_in_secs": 2.1, "kind": "stab" }
  ] }
```

**Beds are not stabs.** Ryan's Tyson concept — fight ambience under the beat,
faded up at chosen moments — means an entry needs a **duration and a level
envelope**, not just an onset, and its matching video is a long clip under the
section rather than a stab on a beat. Both must round-trip. Test material:
`https://www.youtube.com/watch?v=nm0OjxUEaSk` (bed) and
`https://www.youtube.com/watch?v=Fp9xuYeJako` (track) **[RYAN]**.

**READ ONLY.** Never write into an Ableton project. Same one-way rule as
Resolve: scripts never touch a human-edited timeline.

### Traps this machine has already sprung — do not rediscover them

- A GUI-launched process inherits a **minimal PATH**. `ffmpeg` (Homebrew) is not
  on it, and a bare `python3` is Apple's, which has **no numpy** **[V]**. Both
  are handled now; keep it that way when adding entry points.
- Spawn long-running recorders with `DEVNULL` + `start_new_session`, or a caller
  that captures output blocks forever on a pipe the recorder holds **[V]**.
- `ffmpeg … volumedetect` must **not** be run with `-v error` — it suppresses the
  measurement, which then reads as "no audio" **[V]**.
- **Measure loudness, never infer it.** A capture from a device with nothing
  routed produced a flawless h264+aac file at **−91 dB** **[V]**.
- `screencapture -R` is **global desktop points**, top-left origin, negative x
  valid; output **pixels** are points × that display's backing scale **[V]**.
- Config-by-database apps (Stream Deck, Loopback, Companion) **rewrite their
  files from memory on quit**. Quit first, never force-kill **[R]**.
- `build-profile.mjs` needs one-time **Automation permission** to quit the Stream
  Deck app, or Ryan quits it by hand **[V]**.
